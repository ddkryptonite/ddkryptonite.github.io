Project overview

This project automates the creation of personalized operational reports from structured performance data and delivers those reports directly to stakeholders and field workers through the channels they already use.

The system ingests raw records, aggregates metrics by individual and location, calculates key performance trends, and uses the OpenAI API to transform structured data into clear, actionable narrative summaries. The final output is a polished PDF report delivered directly through an API.

Approach & tools

The pipeline moves from raw records to clearer decisions through four stages: collecting source data, transforming and aggregating records, analyzing performance trends, and delivering decision-ready reports.

OpenAI API · BigQuery · VS Code · Git

Project impact

This workflow reduces manual reporting effort, improves consistency across operational summaries, and helps stakeholders receive relevant insights faster. By turning recurring performance data into personalized narrative reports, teams can focus more time on action and follow-up.
